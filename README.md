# Creative Engine

Strategic creative brief and prompt generation engine for Meta ad campaigns.
Turn product URLs, brand assets, and angle directions into high-converting static image briefs and video concepts.

## Architecture & Tech Stack
- **Frontend**: Next.js 15 (App Router), React, TypeScript, Tailwind CSS, Framer Motion, Lucide Icons, Zustand
- **Backend**: FastAPI (Python), Claude / LangChain, Supabase (PostgreSQL + pgvector)
